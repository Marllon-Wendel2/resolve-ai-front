# NextJS, React ou Angular?

Angular traz muitos recursos para um projeto curto, tornando a aplicação desnecessariamente pesada e com uma estrutura maior do que o necessário.

Já o React puro, apesar de ser mais leve, traz pouca coisa pronta. Recursos como gerenciamento de rotas, organização de layouts, renderização no servidor, estrutura de APIs e configuração inicial acabam exigindo bibliotecas adicionais e mais tempo de desenvolvimento.

Por isso, optamos pelo **Next.js**, que utiliza React como base, mas já fornece uma estrutura mais completa para o desenvolvimento da aplicação.

Entre os principais recursos utilizados estão:

- sistema de rotas integrado;
- layouts;
- componentes React;
- hooks;
- API Routes 
- otimização de carregamento;
- estrutura de projeto padronizada.

Dessa forma, conseguimos manter o projeto simples, organizado e rápido de desenvolver, sem adicionar complexidade desnecessária.
